# LG VS EU Daily Brief

Euronews·eurotopics를 매일 아침 읽고 오늘의 5가지(대형 이슈 2 + VS 연관 3)를 고르고, LG전자 VS 제품의 수요·유통 영향 가설과 바이어 확인 행동을 정리하는 페이지.

- `data/YYYY-MM-DD.json` — 하루치 리포트 데이터
- `python3 build.py` — 데이터를 HTML에 넣어 `index.html`, `archive/*.html` 생성
- `DAILY_PROMPT.md` — 매일 실행 지침

뉴스 기반 가설이며 수요 변화를 확정하지 않습니다.
